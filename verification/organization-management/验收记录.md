# 本机组织维护验收记录

2026-11-10；服务 0.6.0；数据库 schema 4；业务契约 1.0。

## 完成内容

- 企业、供热管网、管段由后端提供，支持三级新增、改名/编码修改、启用与停用；不移动父级，不物理删除历史。
- 三级选择与顶栏保持一致，浏览器独立保存本机所选对象；切换演示模式不改变任一侧的组织与历史。
- 停用父级后路径不可用，禁止新增下级、绑定站点和创建新检测；恢复父级后可重新使用。
- 组织修改带 expectedRevision，冲突返回 409 并保留页面输入，需刷新核对后再保存。旧管理员注册表不覆盖本机改名、编码或停用状态。
- 检测及报告来源快照不随组织修改而改变。原站点、模型、采样和报告 ID 保留；schema 3 升级到 4 默认启用旧组织、修订 1。
- 备份恢复兼容 schema 3/4。新组织没有登记管径等信息时不套用演示尺寸，顶栏不展示虚构管径。
