# 数据监测工作台验收记录

日期：2026-11-05。PRD V3.2。依据用户提供的《SHAD「数据监测」模块 UI.docx》（纯文字，无嵌入图片）。原界面黑灰橙色及字体保留；侧栏异常检测与旧地址不变，页面标题为数据监测。

## 文档要求与实现

| 要求 | 已实现 |
|---|---|
| 左侧选择数据 | 仅实际可用参数，温度/压力/流量分类折叠、单选、多参数对比及状态标识 |
| 中间监控 | 监测范围最新有效数值/单位/时间/状态，历史趋势、范围、图例、对比、红色异常点与区间 |
| 数据明细 | 采集时间、参数/测点、数值、单位及状态；8条分页，异常/质量筛选、全部匹配CSV |
| 右侧找异常 | 所选/全部参数范围、数量、事件、详情、数值依据；点击联动曲线缩放及对应采样页 |
| 底部做检测 | 页内时间/参数/算法配置、执行与状态、复制/重试、结果、自动保存任务、历史查询及AI诊断 |
| 数据边界 | 质量问题与运行异常独立；无数据不造零值；无供水压力不补造字段；明确模拟来源及非实时 |
| 功能边界 | 不重复管网拓扑，不输出具体原因；保留单/多选数值事件传递到AI诊断 |
| 手机 | 纵排、选参数/看趋势/查异常/做检测页内快捷导航、局部表格滚动和单参数图表控制 |

监测与检测时间独立。监测输入非法保留上次有效视图；显式带入按钮更新检测表单。持续异常最多标记到来源检测结束；超出覆盖区域显示部分未检测。历史对象快照不随顶栏改写，历史筛选不自动替换当前详情。
