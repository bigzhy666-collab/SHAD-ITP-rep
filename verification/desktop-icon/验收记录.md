# 0.7.1 图标修复验收

日期：2026-11-14。范围：Windows 程序、窗口、任务栏、快捷方式与安装程序图标；业务界面、模型和数据库保持原有行为。

## 原因与修复

- 0.7.0 转换时使用 `thumbnail`，该操作不会放大小图；原始 81×78 图形放在 256×256 透明画布中，导致实际显示过小。改为等比放大至 256×247，再生成七种 ICO 尺寸。
- 本机正式安装记录已经是 0.7.0，不能根据安装路径断言是旧程序。用户桌面 SHAD.lnk 的 IconLocation 为 `,0`，未显式指定图标；旧 Python 外观与 Windows 的历史图标缓存一致，但未直接取证缓存内容。
- 快捷方式和窗口显式使用外置的版本化图标 `resources/shad-0.7.1.ico`；快捷方式与窗口的 AppUserModelID 统一为 `SHAD.Desktop`。向导默认创建或更新桌面快捷方式，用户可取消；升级不沿用此前未勾选的设置。

## 已通过

- ICO 文件及实际桌面 EXE 内嵌的 16/24/32/48/64/128/256 图像均检查非透明主体占比及橙色标记；外置图标与源构建资产字节一致。
- 通过 Windows `WM_GETICON` 读取真实测试窗口的小图标与大图标，检查主体占比并导出 `window-icon-16.png`、`window-icon-32.png`，已查看 32 像素结果。大图标主体范围为 (0,1)-(32,31)，不再缩在画布中央。此项验证窗口实际图标，不等同于用户当前 Windows 外壳缓存的显示结果。
- 既有桌面生命周期 4 项通过：启动与单实例、原生下载与安全退出；端口冲突；服务复用与显示异常恢复；旧服务界面识别。新增实际窗口图标测试单独通过，共 5 项。
- 图标专用临时安装：以独立 AppId 安装到项目中文/空格目录，事先创建一个旧快捷方式；不覆盖 /TASKS 选择，验证默认安装确实替换该链接。实际生成的桌面/开始菜单链接均指向桌面程序、显式 ICO 文件与正确的 AppUserModelID。验收后卸载临时安装。
- 临时验收包仅为验证图标，将所有快捷方式位置重定向至临时安装目录，使用独立互斥标识；没有启动后端，也没有修改用户桌面、正式安装或业务数据。本轮不重复证明原有运行时安装保护，既有记录保留在 0.7.0 验收中。
- 0.7.1 正式安装包编译成功，检查清单与 SHA256 见 `artifact.json`。仅本地提交，不推送；全新 Windows 离线验收继续暂缓。
