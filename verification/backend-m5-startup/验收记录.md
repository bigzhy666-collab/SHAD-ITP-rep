# M5 第一批：本地启动与备份恢复验收记录

日期：2026-11-09；服务 0.5.0；数据库 schema 3；PRD V3.9。

## 本轮交付

- 四个 Windows 入口：启动、停止、查看状态、备份。启动后台服务并打开本机模式；重复启动复用同一实例。
- 启动先预留端口、取得数据目录锁，再初始化数据库及执行检测队列。端口冲突和离线维护占锁不会先改写数据库。
- 停止通过本机接口校验实例及私有凭据，不按进程名称或 PID 强杀；跨站请求被拒绝，状态响应不泄露停止凭据。
- 离线备份包含 SQLite 完整快照、数据库引用的原 CSV、文件校验值及模型登记；不包含模型代码、运行环境、日志、停止凭据或浏览器演示数据。
- 恢复逐项核验路径、大小、SHA-256、数据库完整性、源文件和已安装可信模型；全部通过后发布到新目录，不覆盖原工作区。失败清理本次临时目录。
- 启动脚本默认使用 `%LOCALAPPDATA%\SHAD\data`；原开发入口仍默认 `backend/data`。旧数据使用方式及迁移流程见[启动与备份说明](../../docs/本地软件启动与备份.md)。
- 沿用已有界面、图标、图表和按键布局；前端只补充启动地址强制进入本机模式的逻辑。
