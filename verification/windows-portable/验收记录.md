# Windows x64 便携运行包验收

日期：2026-11-10。服务 0.6.0，数据库 schema 4。

## 本轮交付

- Windows x64 文件夹式程序，包含前端静态资源、后端、Python 运行时和历史示例模型；双击启动、停止、状态、备份脚本。
- 冻结程序使用同一 EXE 启动后台服务，不调用系统 Python；原开发启动方式仍保留。
- 修复冻结程序所需的 scipy 动态模块和模型适配源文件路径；命令输出统一 UTF-8。
- 构建脚本与使用说明提交 Git，二进制包、中间文件、日志不提交。

## 结果

1. 后端回归：`171 passed`，一个现有 Starlette/AnyIO 弃用警告。
2. 实际 EXE 验收通过；最终 ZIP 再解压到含中文和空格的目录后重复验收通过。测试用的是包内模型、包内示例登记和真实 TCP，不是模拟接口。机器记录见 [frozen-backup-restore.json](frozen-backup-restore.json)。
3. EXE 子进程清除 PYTHONHOME/PYTHONPATH，PATH 仅保留 Windows System32；启动、模型推理、备份和恢复无需系统 Python/Node。
4. 覆盖重复打开同一实例、真实页面托管、停止凭据校验、外来 Origin 拒绝、端口冲突、运行中拒绝备份、优雅停止及控制记录清理。
5. 导入 60 点合成数据，运行仓库实际 M1_s7 模型，得到持久化检测与一个确认事件；报告两版本、备注、归档状态在备份恢复和重启后完全一致，幂等提交继续有效。
6. 备份只包含数据库、原始 CSV 和清单，不混入代码、模型或实例控制凭据；恢复到新目录后同端口重新启动成功。
