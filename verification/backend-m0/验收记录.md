# 本地后端 M0：模型接口验收

日期：2026-11-09

本轮范围：制定后端实施计划，建立加载已训练模型的本地接口；不实现训练，不宣称已完成 CSV、后台任务、数据库、报告归档或安装包。

## 验证结果

| 验证 | 结果 |
|---|---|
| 后端自动化测试 | 46 项通过 |
| 模型一致性 | 实际 `M1_s7.pkl` 的 HTTP 逐点输出与同输入直接 `model.detect()` 对照，浮点/布尔/计数一致；确认区间与原 `segments()` 对照一致 |
| 缺口与边界 | 独立连续块实际推理计数重置；无异常成功、告警衰减、缺失/越界、字段/单位/时区/跨站错误均覆盖 |
| 模型登记 | 文件校验值、可信路径、缓存后产物变化、依赖版本不匹配、不可用状态均覆盖 |
| 实际 HTTP | 启动真实 CLI 子进程，经本机 TCP 请求状态、模型、推理、OpenAPI；结束后自动停止 |
| 前端托管 | 实际服务返回四业务地址的现有 dist 页面；API 404 仍是 JSON，未实现业务返回能力关闭 |
| 本机访问边界 | Host/Origin、请求体 5 MiB 限制及 chunked 请求限制通过 |
| 依赖 | `pip check` 通过，记录完整依赖锁文件 |

实际 HTTP 检查记录见 [http-smoke.json](http-smoke.json)。输入为 60 个合成半小时采样，真实模型返回 60 个逐点结果、1 个确认区间。**这是接口一致性验证，不是现场准确率验证，也不是完整前后端检测任务联调。** 示例模型和时区测试约定均明确标识，未绑定国内组织。

## 复现

在仓库根目录 PowerShell 中执行，先按模型接口文档安装独立环境依赖，并保证现有 `dist` 存在（需要时运行 `npm run build`）。

```powershell
.\.venv-backend\Scripts\python.exe -m pytest backend/tests -q
.\.venv-backend\Scripts\python.exe -m backend.tests.http_smoke --out verification/backend-m0/http-smoke.json
.\.venv-backend\Scripts\python.exe -m pip check
```

本轮未修改前端组件、布局、图表或 TypeScript，未重复运行原前端契约/视觉测试。真实 HTTP 检查验证了现有构建产物的页面路由托管；原前端浏览器测试仍使用拦截数据，不并入本轮模型验证数字。

测试环境有一条 Starlette 测试客户端引用 AnyIO 旧别名的 DeprecationWarning；不影响本轮通过结果，未屏蔽。完整验证环境版本见 `backend/requirements-lock.txt`。
