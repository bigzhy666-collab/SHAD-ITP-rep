# M3 本机报告持久化验收记录

日期：2026-11-09；服务 0.4.0；数据库 schema 3；PRD V3.8。

## 已完成

- 报告创建/详情/历史、备注、归档、新版本接入 SQLite；从一个成功检测中单选或多选事件，保存完整曲线及独立来源快照。
- 创建与新版本同事务保存去重键；并发同键只生成一份。新版本按系列递增，不改变旧版本证据、备注或归档时间。
- 备注最多 2000 字，expectedRevision 防止多窗口覆盖；冲突保留输入，读取最新已保存备注核对后继续保存。
- 归档锁定备注；支持归档响应丢失后的安全重试。数据库写入失败回滚，恢复后可重试。
- 保存后地址包含 reportId，刷新恢复同一版本；导出前自动保存报告及备注，Word/PDF 共用保存快照；导出失败不改变归档状态。
- 历史接口只返回摘要，详情再读取曲线。v1/v2 数据库可自动升级到 v3，保留原数据；服务重启后保留报告、版本和去重关系。
- 沿用现有浅色界面、图标、图表和按钮布局，只补充保存反馈、修订冲突核对及真实报告行为。
