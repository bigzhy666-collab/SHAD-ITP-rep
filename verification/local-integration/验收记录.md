# 本机服务前端与接入准备验收

日期：2026-11-08

## 验证范围与限制

本轮交付 Vue 前端、本机 API 客户端及后端交接说明，没有实现本地 HTTP 后端，也没有实际运行 Python 模型进行联调。以下图片、下载文件与流程使用 Playwright 契约测试数据；“接口联调模型（非真实推理）”仅为测试标识，不能当作正式检测性能或真实诊断结果。

## 验证结果

| 检查 | 结果 |
|---|---|
| 单元测试 | 60 项通过，覆盖原功能以及接口错误、超时、取消、幂等、分页、CSV 和报告来源 |
| 完整浏览器回归 | 35 项通过，包含原演示与本机接入 |
| 最终本机专项回归 | 最后修改后重新执行，9 项通过 |
| 生产构建和 TypeScript | 通过；保留 ECharts / PDF 库的原有大文件体积提示 |
| 机械设计检查 | 检查新增页面、公共框架、图表及样式，返回空发现列表 |
| 视觉检查 | 已查看桌面/手机实际截图及两页 PDF 渲染，中文、图表和操作可读 |
| 导出内容 | Word 为有效 ZIP/XML 文档，PDF 两页；两者均包含中文备注、来源事件、版本及图表 |
| 文档校验 | 接口文档 JSON 示例、相对引用和 Markdown 围栏有效 |

专项流程覆盖：

1. 服务不可用时不回退模拟数据，重新连接、模式保存及恢复。
2. CSV 时间/八个测点映射与原始单位确认，multipart 上传本站数据。
3. 创建任务、实际排队/执行/完成状态、完整分页、分数曲线和事件定位。
4. 无异常作为成功结果；失败任务创建新重试记录，保留来源。
5. 原因诊断能力未启用时禁用，未存档临时报告仍可下载 Word/PDF。
6. 能力开启后的真实契约调用：诊断、报告、备注冲突、归档锁定和新版本。
7. 事件选择刷新和返回后恢复，非法时间不创建任务。
8. 后端返回错误任务/站点来源时阻止展示。
9. PDF 中文字体失败后保留备注并允许重试；刷新不覆盖未保存备注。
