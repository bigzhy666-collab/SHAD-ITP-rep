# SHAD 本地报告接口说明

版本：M3 · 服务 0.5.0 · 数据库 schema 3 · 2026-11-09

## 能力与使用路径

`reportPersistence=true`。报告存入本机 SQLite，刷新、关闭界面及重启服务后仍可读取。`causeDiagnosis=false`：当前模型只能识别运行状态数值异常，阶段报告没有故障归因或具体解决方案；接口拒绝附加任意 diagnosisId。演示模式的分析结果不会混入本机报告。

启动方法沿用 [数据接口](本地数据接口说明.md)。先完成本站数据导入和真实检测，在数据监测单选/多选同一任务的确认事件，进入 AI诊断：

1. 核查来源、分数曲线和选定事件，填写最多 2000 字备注。
2. “保存报告与备注”固定证据；“保存并归档”先保存备注再锁定该版本。两次操作分别有事务，归档失败时已保存备注不会丢失，可重试。
3. 保存后地址带 reportId，刷新恢复同一报告；历史中可打开其他版本。
4. “创建新版本”从当前保存快照复制证据与备注，版本号按系列递增。旧版本不变；新版本未归档，可编辑备注。若要更换事件或检测来源，应从检测页重新选择并创建另一报告系列。
5. Word/PDF 共用同一份已保存快照。尚未保存的报告或备注在导出前先保存；保存失败则不导出。无报告能力的旧后端兼容临时 V0 导出，但不声称已存档。

## 接口

所有接口使用 `/api` 前缀、同源本机访问与通用 `{requestId,data}` / `{requestId,error}` 响应。分页从 1 开始，pageSize 为 1–500。

| 方法与路径 | 输入 | 响应 |
|---|---|---|
| `POST /reports` | `{detectionId,eventIds,diagnosisId:null}`；必需 Idempotency-Key | 201，完整 Report |
| `GET /reports` | page、pageSize，可选 detectionId、archived=true/false | 200，分页 ReportSummary |
| `GET /reports/{id}` | 报告 ID | 200，完整 Report |
| `PATCH /reports/{id}/note` | `{note,expectedRevision}` | 200，完整 Report |
| `POST /reports/{id}/archive` | `{expectedRevision}` | 200，完整 Report |
| `POST /reports/{id}/versions` | `{expectedRevision}`；必需 Idempotency-Key | 201，新版本完整 Report |

Idempotency-Key 长度 1–128，允许字母、数字、点、下划线、冒号和短横线。创建与每个来源报告的新版本使用独立作用域；同作用域同键同配置返回同一报告的当前状态，同键不同配置返回 409。事件顺序不同视为相同选择；重复事件 ID 则拒绝。幂等记录与报告同事务写入，失败不占用键，重启后仍保留。

前端在浏览器保存不确定请求的键，成功后清除。若有意再建一份报告/版本，使用新键；重复点击、超时重试和重启重试使用原键。新版本有自己的 ID，不能用旧报告 ID 假装生成了新版。

## 报告结构

| 字段 | 含义 |
|---|---|
| id、title | 唯一 ID；后端根据固定站点名称生成标题 |
| seriesId | 同系列标识；首版等于自身 ID |
| sourceReportId | 首版 null；新版本记录复制的来源报告 ID |
| detectionId、diagnosisId | 来源成功检测；当前 diagnosisId 固定 null |
| eventIds | 非空、唯一、来自同一检测和站点；后端按事件时间排序 |
| version | 系列版本号，从 1 开始；同系列版本唯一 |
| revision | 本版本修订号，从 1 开始；备注实际变化或首次归档时加 1 |
| createdAt、archivedAt | UTC ISO 时间；未归档时 archivedAt=null |
| note | 纯文本，最多 2000 字，可为空；前端转义显示 |
| snapshot | `{task,result,points,events,diagnosis:null}`；独立完整证据 |

task 保存成功任务和对象/数据/模型来源。result 包含实际检测摘要、预处理版本、请求与实际采样范围、质量和演示提示。points 包含整个任务的全部逐点结果，超过一页也不截断；events 仅包含所选事件。保存前验证来源快照、结果点数和事件数量一致。浏览器不能上传自制 snapshot、模型权重、原因、置信度或解决方案。

`GET /reports` 返回 **ReportSummary = Report 去掉 snapshot**，其余字段相同；前端已同步使用摘要类型。列表按 createdAt DESC、id DESC 稳定排序，同一请求的总数和分页在同一读事务取得。点击详情再读取曲线，避免历史列表传输所有报告的大量点。

## 修订、归档和恢复

- 备注/归档/新版本先在写事务中校验 expectedRevision。过期返回 409 `REVISION_CONFLICT`，不会覆盖已保存内容。
- 前端保留当前备注输入，提供“读取最新版本，保留当前备注”；显示最新已保存备注供核对。用户确认内容后再次保存，不自动覆盖他人修改。
- 同样的备注使用当前 revision 保存是无操作，不增加修订号；若响应丢失后用过期号重试，可核对最新版本再继续。
- 归档锁定备注。已归档版本重复归档时，当前号或首次归档前一修订号返回同一归档记录，避免响应丢失导致重复归档。其他过期号返回冲突。
- 新版本从已保存快照复制，不重新读取当前全局管段或重新运行模型。允许从未归档或已归档版本复制。前端会先保存未归档版本的待保存备注，再请求新版本。
- Word/PDF 文件生成在浏览器完成，没有额外后端排版接口。归档状态不会因导出成功或失败而变化；字体或文件生成失败可重试。

## 错误

| code | HTTP | 含义与恢复 |
|---|---|---|
| INVALID_REQUEST | 422 | 非法请求、额外字段、重复/空事件、备注过长、非法键或修订号 |
| NOT_FOUND | 404 | 来源检测或报告不存在 |
| RESULT_NOT_READY | 409 | 检测未成功，不能形成报告 |
| SOURCE_MISMATCH | 422 | 事件不属于当前检测/站点 |
| RESULT_UNAVAILABLE | 503 | 完整结果缺失或来源不一致，停止保存 |
| CAPABILITY_UNAVAILABLE | 503 | 原因诊断能力未接入，不能附加 diagnosisId |
| IDEMPOTENCY_CONFLICT | 409 | 同提交键被用于不同配置 |
| REVISION_CONFLICT | 409 | 其他窗口已更新，保留输入并核对最新版本 |
| REPORT_ARCHIVED | 409 | 归档备注不可改，请创建新版本 |
| STORAGE_WRITE_FAILED | 500 | 写入已回滚；恢复磁盘/权限后用同键或修订号重试 |

## 存储与升级

schema 3 新增 reports、report_submissions 及历史/来源索引。原有 schema 1/2 自动按事务逐级迁移，保留 CSV、采样、模型登记、检测和幂等记录；新旧版本唯一约束和外键生效。旧服务禁止打开更高版本数据库，不进行降级破坏。

报告证据写入独立 JSON 快照，后续来源记录变动不会改变旧报告。报告创建、版本递增、去重记录提交为同一事务；备注或归档写失败也全部回滚。当前无删除报告功能；M5 第一批已提供停止服务后的校验备份与恢复到新目录，见 [启动与备份](本地软件启动与备份.md)；自动定时备份与安装包尚未交付。

验收与可下载样本见 [M3 记录](../verification/backend-m3/验收记录.md)。使用真实示例产物和明确标记的合成数据完成集成测试，不代表本站模型适用性或现场准确率。
