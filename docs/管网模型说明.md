# 管网模型首页与演示异常

更新：2026-11-14。本说明优先于旧版四模块入口规划，其余真实业务契约不变。

## 导航与启动

侧栏依次为管网模型、总览、管网管理、数据监测、检测报告。根地址重定向至 `/model`；安装程序启动打开 `/model?service=local`。已有 `/overview`、`/networks`、`/detections`、`/reports` 深链接继续可用。

## 场景来源与边界

依据仓库提交 `d22938bca77cf89a055e44a3a56316a22fd43438` 的《供热管网3D原型.html》拆分，采用本地 Canvas 立体投影，无 iframe、整页截图或外部 CDN。Vue 页面位于 `src/views/PipeModel.vue`，渲染模块为 `src/model/scene.ts`，几何/组织与告警配置为 `config.ts`，时序为 `heat.json`，样式限定在场景容器内。

顶栏保留真实业务对象路径；场景内部三级选择仅切换演示布局，绝不写入真实业务对象。页面明确显示「示意街区 · 演示时序 · 未联动真实检测」。图中名称、运行值和状态均为演示，不能作为实际运行判断。

## 操作

- 单击换热站、能源站或异常红点后，约 400 毫秒平滑居中并适度拉近，保留当前观察角度；重复点击不持续放大，已手动拉近时保留更近的比例。支持键盘聚焦站点后按 Enter。
- 聚焦后拖动围绕当前站点旋转；右键平移、滚轮缩放保持可用。手动操作、切换对象、场景或退出页面取消旧聚焦动画。「复位视角」清空选择和详情，返回全景。
- 以不被面板遮挡的可视区域中心为准；桌面避让两侧浮卡，手机将详情放到场景底部并保留上方站点观察区域。开启减少动态效果时直接居中。
- 企业、管网、管段选择切换独立示意场景；保留地面、地下、透明地面、剖切以及图层开关。
- 播放/暂停、拖动时间轴或「定位演示异常」同步更新数值与标记。
- 点击站点、管线或异常标记共用详情区域，展示对象、时刻、演示指标和触发条件。

## 演示异常规则

原型时序字段 `s_hc1_supply_temperature` 大于 80 ℃时，显式配置的站点 `S3` 及其关联管线为受影响对象。站点集合独立配置，未在集合内的对象不标红。一个站点及其关联管线共用站点位置上的可点击红点，详情列出关联管线编号，避免密集标记遮挡；多个配置站点可同时显示。

红点跟随场景视角与缩放重新投影，在正常时段取消；关联管线以红色突出。标记使用缓慢脉冲，系统开启减少动态效果时改为静态，并保留「异常」文字。没有新增检测接口、数据库字段、原因推理或方案建议。

## 加载与资源

场景和时序随本地程序打包并按需加载。加载失败显示重试入口；首次打开本机程序不需要互联网。离开页面停止播放，取消事件监听、延时回调和尺寸观察，移除标记。手机上工具栏换行、指标浮卡收起、详情滚动；桌面保持场景主布局。
