## 安装与验收顺序

1. 等镜像完整下载，使用 `VBoxManage unattended detect --iso 镜像路径` 检查介质，而不是只检查文件存在。记录系统版本、ISO 大小与 SHA-256；若官方提供校验值则比对。
2. 仅将 ISO 挂载到此测试虚拟机，安装 Windows；若使用无人值守安装，随机账户凭据仅保存在被忽略的测试目录，不提交或打印密码。安装增强组件可用于只读共享与测试控制，不安装 Python/Node。
3. 系统首次启动完成后关机，保存干净快照，再确认网卡 none。若评估激活需要联网，限虚拟机完成激活，之后断开虚拟机网络再开始验收，不关闭宿主机网络。
4. 在干净系统内从只读 SHADDelivery 拷贝安装包到客体本地目录并安装；先不登记模型，检查空状态与所有页面。
5. 在这个新建测试系统内显式启用历史示例登记，导入 synthetic.csv，时区 Etc/UTC，字段同名映射，单位见 units.json。该数据不代表现场模型有效性。
6. 按 [全新 Windows 离线验收](全新Windows离线验收.md) 测试实际模型任务、事件、报告备注/归档/版本、Word/PDF、重启恢复、备份恢复、升级和卸载保留数据。
7. 保存客体系统版本、结果、截图、导出样本与日志，另外记录是否确实断网。只读共享不能直接写回结果；测试结束后使用专用结果目录或客体控制工具导出，勿改为整盘可写共享。
