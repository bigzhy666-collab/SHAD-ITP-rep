# 全新 Windows 离线验收

此文档是待执行步骤，不代表验收通过。当前开发机没有可用的 Windows Sandbox，不能据此宣称全新系统已验收。应使用无 Python、Node 的全新 Windows 10/11 x64 测试机或虚拟机快照。

1. 联网准备：拷贝安装包、其 SHA-256 清单、已授权的本站模型与注册表、UTF-8 CSV 样本及预期结果；不拷贝开发环境。合成示例仅验证程序通路，不代替本站模型验收。
2. 记录系统版本和空白环境，断开测试机网络，核对安装包 SHA-256。后续全程离线，不在正在使用的工作电脑随意断网。
3. 普通用户执行安装向导，选择中文及空格目录，检查可选桌面入口、开始菜单入口和卸载入口，不要求安装 Python、Node 或联网下载依赖。
4. 启动并确认浏览器地址为 127.0.0.1。刷新四个页面，检查字体、图表、空状态；重复启动复用实例。关闭浏览器后用“停止 SHAD”正常停止。
5. 默认业务数据位于当前用户 AppData\Local\SHAD\data。按模型接口说明登记可信模型，导入 CSV，核对质量门控、检测逐点结果和异常事件与基准数据一致。
6. 生成检测报告，保存备注、归档、新建版本，导出 Word/PDF。联网下载字体不得成为导出前置条件；复制文件到有阅读器的电脑确认中文、曲线和章节完整。
7. 重启系统，确认历史与备注仍在。停止后备份，恢复至新目录，以同一可信模型启动恢复目录，核对采样、事件、报告版本和归档。
8. 服务运行时尝试更新与卸载，应要求先停止，不强制终止检测。停止并备份后覆盖安装，确认数据未改变。
9. 卸载后确认程序、快捷方式与卸载入口移除，数据库、原始 CSV、自定义目录和备份保留。重新安装后使用原目录，确认历史仍可读取。
10. 保存系统版本、安装包校验值、安装日志、截图、导出样本、实际结果与失败信息。通过后单独提交验收记录；不把开发机 PATH 隔离测试当作本项通过。

当前安装包未签名。应记录系统实际提示，不要求关闭系统保护；正式分发前按组织的签名和发布流程处理。
