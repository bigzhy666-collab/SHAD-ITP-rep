# SHAD 独立桌面软件 0.7.3

## 使用

安装后双击 SHAD 图标，默认进入「管网模型」。软件自带 Electron 页面运行环境、Python 本机服务、前端资源、中文导出字体及仓库历史训练模型。Windows 10/11 x64，无需安装 Python、Node.js、Chrome 或 WebView2，运行无需联网下载组件。

现有页面、站点聚焦、检测和报告业务继续使用。场景红点仍为演示，不自动代表现场真实异常。包内历史训练模型不自动登记为本站模型，应使用适用站点的登记与导入流程；原因和方案诊断继续关闭。

使用用户提供的图标，源图片保存在 `desktop/icon-source.png`，转换出 PNG 与含 16/24/32/48/64/128/256 尺寸的 Windows ICO，应用于程序、窗口、快捷方式及安装程序。

0.7.1 修正上一版图标缩放：原始 81×78 图片现在按比例放大至 256×247，再居中放入画布，避免大面积透明边距导致任务栏主体过小。快捷方式显式使用 `resources/shad-0.7.1.ico`，窗口使用相同文件及 `SHAD.Desktop` 标识。安装向导默认勾选「创建或更新桌面快捷方式」，不沿用上次未勾选的任务设置；用户仍可取消。

已安装用户：先正常退出 SHAD，再安装 0.7.1 到原目录，保留勾选上述快捷方式选项。升级保留业务数据。本轮未自动关闭用户窗口或覆盖正式安装；旧窗口需在更新后重新打开才使用新版图标。

0.7.2 进一步去除截图自带的白色外沿，按原图深灰外框弧度补齐完整圆角，外部保持透明；内部曲线和红色节点不变。新版图标路径为 `resources/shad-0.7.2.ico`。退出当前软件后覆盖安装 0.7.2，保留创建或更新快捷方式选项。

0.7.3 修复模型左侧指标与图例重叠：矮窗口中指标区独立滚动，可点击或 Tab 聚焦后用键盘滚动；图例与指标保留间距。手机沿用隐藏指标、保留图例的方式。站点聚焦适配新的面板层级。安装到原目录前先正常退出软件。

## 启动与退出

- 独立窗口显示启动状态；服务就绪后进入 `/model?service=local`。重复启动激活已有窗口，不创建第二个窗口。
- 保留原生标题栏与 Windows 窗口操作，记住窗口大小、位置、最大化状态；恢复时限制在可见屏幕区域，高分屏可能存在数像素边框舍入。
- 启动失败显示重试和日志路径。复用已有服务时核对实际界面文件，发现旧版界面先提示退出旧版，避免新窗口误显示旧页面；不擅自停止外部服务。
- 关闭即退出，不常驻托盘。运行/排队检测以及未保存备注先提示，默认返回软件。确认后仅安全停止自己创建或可确认由此前桌面窗口创建的同一服务实例。
- 排队任务随数据库保留；下次启动继续执行。被中断的运行任务使用现有失败/重试机制，已保存历史、报告和原始数据保留。
- 停止失败显示提示并允许再次尝试，不按 PID 强杀业务服务。HTTP 连接退出等待上限 10 秒；这不等于强制终止模型计算。
- 复用外部服务时，退出只关闭窗口。显示进程异常提供重新连接；未保存的界面内容不保证在显示进程崩溃后保留。
- Word/PDF/CSV 导出显示原生保存位置选择框，取消后不保存文件。沿用现有文件导入控件。

## 数据与维护

业务目录继续为 `%LOCALAPPDATA%\SHAD\data`，窗口设置、归属记录及桌面日志在 `%LOCALAPPDATA%\SHAD\desktop`，升级/卸载保留外部业务数据。继续使用自定义工作区时，先退出软件，再通过 `SHAD.exe --data-dir <原目录>` 启动。

应用版本为 0.7.3；后端服务仍为 0.6.0、契约 1.0、schema 4，无数据库迁移。原开始菜单维护入口保留，实际控制程序现在位于 `resources/backend/SHAD.exe`；命令及备份恢复说明随安装目录的《使用说明.txt》提供。

新增的内部桌面通信仅允许报告组件报告脏状态，及启动页重试/状态显示；校验主窗口、主框架与加载来源，不向页面开放 Node.js、文件系统或任意命令执行。页面隔离和沙箱开启，拒绝任意页面跳转、新窗口及权限请求。

CLI 增加可选 `stop --expected-instance <实例ID>`，实例变化时拒绝停止；原命令调用保持兼容。另有安装互斥保护进程，在窗口启动失败或关闭期间也防止覆盖安装。新增窗口与 CLI 行为不增加业务 API、训练流程或数据库字段。

## 开发和构建

开发环境使用 Node 24；依赖锁定 Electron 45.3.2、@electron/packager 20.3.0。先准备既有 `.venv-backend` 和构建依赖，再运行：

```powershell
npm ci
node node_modules/electron/install.js
npm run build:desktop
```

构建后端、前端，再合成桌面包；运行包在 `release/desktop/`，原后端包在 `release/windows/`。已有本轮后端包时可通过 `packaging/windows/build-desktop.ps1 -BackendDir <后端包>` 重新封装窗口。

使用 `packaging/windows/build-installer.ps1 -PackageDir <桌面包> -Compiler <ISCC.exe>` 生成 Inno Setup 安装包。构建入口拒绝使用旧的纯后端包，缺少当前版本的外置图标时停止。构建缓存中的 Electron ZIP 每次按 npm 官方校验清单验证 SHA256。

重新生成图标时，在安装 `packaging/windows/requirements-icons.txt` 的 Python 环境运行 `packaging/windows/build-icons.py`。图标像素与可执行文件验收运行 `packaging/windows/test-icons.py --exe <桌面程序>`；新增桌面图标测试同样需要该 Python 环境，可用 `SHAD_ICON_PYTHON` 指定解释器。`test-icon-shortcuts.ps1` 使用专用安装标识、临时目录及重定向快捷方式检查真实安装输出，既不更新用户桌面也不启动服务。

桌面验收配置为 `playwright.desktop.config.ts`，设置 `SHAD_DESKTOP_EXE` 后运行；提供 `SHAD_PREVIOUS_BACKEND_EXE` 可验证旧版界面识别。所有测试使用项目内临时工作区，不使用默认业务目录。

## 验收边界

0.7.0 业务验收详见 `verification/desktop-shell/验收记录.md`；0.7.1 图标修复验收见 `verification/desktop-icon/验收记录.md`。本机实际桌面程序、文件导出及冻结模型流程分别验证。最初检测到正式安装及运行中的旧版时，测试主动停止。旧进程退出后，以独立验收安装标识在项目临时目录验证了 0.6.0→0.7.0 数据保留升级、运行保护及卸载保留数据；未覆盖正式安装。本轮结果与先前版本记录区分，全新 Windows 虚拟机离线验收继续暂缓。
